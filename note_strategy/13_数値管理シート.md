# 13. 数値管理シート

CSVファイル：`13_数値管理表.csv`（UTF-8 BOM付き、数式入り、26週分）

## 使い方（Googleスプレッドシート）

1. Googleスプレッドシートを新規作成 →「ファイル」→「インポート」→「アップロード」で `13_数値管理表.csv` を選ぶ
2. 「区切り文字：カンマ」「テキストを数値、日付、数式に変換：はい」でインポート
3. J列（購入率）・AA列（継続率）を選択 →「表示形式」→「数字」→「パーセント」
4. 毎週日曜に1行ずつ記入（所要15〜20分）

## 毎週見るポイント（優先順）

1. **購入率（J）**：2%未満が続く → 無料部分・目次・タイトルを改善
2. **販売ページPV（H）**：少ない → X告知の仕方・無料記事からの内部リンクを改善
3. **固定ポストクリック（Q）・プロフィールアクセス（P）**：少ない → 固定ポスト1本目のフックを変える
4. **インプレッション（O）**：伸びない → リプ15分を守れているか、柱の配分を見直す
5. **販売告知回数（T）**：投稿数の10%を超えていたら減らす

## 月次の振り返り（毎月第1日曜）

- 月合計：販売数、売上、手取り推定（−270円）、新規フォロワー、無料記事PV
- 「一番売れた記事」と「一番PVが多い無料記事」の組み合わせを確認 → 次の記事のテーマ
- 改善は**1か月に1〜2個まで**（同時に変えると何が効いたか分からなくなる）

## メンバーシップ導入後に追加で見る指標（月次）

| 指標 | 目安（仮説） |
|---|---|
| メンバー数 | 第17章の逆算表と比較 |
| 新規参加数 | 退会数を上回っているか |
| 退会数・月次退会率 | 10%以下を目標、15%を超えたら特典・運用量を見直す |
| 継続率（月次） | 90%以上が目標 |
| 掲示板の投稿・コメント数 | 増えなくても問題なし（参加は任意）。ゼロが続くなら運用負荷の高い特典を縮小検討 |
| 特典記事の閲覧数 | メンバー数に対する割合。50%を切るなら記事の内容・頻度を見直す |
| メンバー経由の売上・手取り | 単発販売とのバランス |
