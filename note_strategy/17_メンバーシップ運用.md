# 17. メンバーシップを運用する場合

> **前提：単発販売で需要と信頼を確認した後に導入する。**
> 仕様の出典：note公式ヘルプ（`99_出典一覧.md` A5〜A7、確認日2026-10-03、検索経由の確認のため**開始前に必ずヘルプを開いて再確認**）

## 0. 2026-10-03時点で確認した仕様（要点）

| 項目 | 内容 |
|---|---|
| 会費 | 100円〜50,000円（noteプレミアム／note proは上限100,000円） |
| プラン数 | 公開できるのは5つまで（無料プランは1つまで） |
| 手数料 | 事務手数料（決済手段別）＋プラットフォーム利用料10%（有料記事と同じ） |
| 掲示板 | オーナーとメンバー限定。**投稿はオーナーのみ、メンバーはコメント可** |
| 請求日 | **2026年8月3日以降の新規参加者は、入会日が毎月の請求日**（入会日から1か月分が無料扱いという記載あり＝**意味を要再確認**）。8月2日までに「毎月1日の請求を継続する設定」をしたメンバーシップは1日請求のまま |
| 日割り | 毎月1日請求のメンバーシップは月途中参加でも日割りなし |
| 退会 | メンバーは次回請求日の前日までに退会すれば次回以降の請求なし |
| 返金 | 会費は原則返金不可（返金はクリエイターに委ねられる）。**オーナーがメンバーを退会させた場合、その月の会費は返金される** |

→ これから開設する場合、**請求日は入会日ベースが標準**になる可能性が高い。「入会日から1か月無料」の扱いが手取り計算に影響するため、**開設前に公式ヘルプで正確な仕様を確認**すること（未確認）。

## 1. 導入タイミングの判断基準（すべて満たしたら開始）

| # | 条件 | 目安（仮説） | 理由 |
|---|---|---|---|
| 1 | 有料noteの累計購入者数 | **100人以上**（ユニーク） | メンバー化率5〜10%と仮定すると初月5〜10人。これ以下だと掲示板が寂しく、モチベーション維持が難しい |
| 2 | リピート購入者 | **10人以上**が2本以上購入 | 「継続して払う人」がいる証拠 |
| 3 | 毎週読んでくれる読者 | 無料記事に毎回スキをくれる人が**30人以上** | 週1特典を楽しみにする層 |
| 4 | 月の単発売上 | **手取り月2〜3万円**が2か月連続 | 単発の流入が安定していないと新規メンバーが入らない |
| 5 | ネタの在庫 | **3か月分（12本以上）**の相談回答・ワーク・実践記録の下書き | 開始後に枯渇するのが最大の失敗 |
| 6 | 運用時間 | 下の運用カレンダーを**平日1〜2時間・休日3〜5時間の中で**2週間試運転できた | 単発の記事執筆・X運用と両立できるか |
| 7 | 要望 | 「続けて読みたい」「一緒に実践したい」という声が複数 | 需要の確認 |

**1つでも満たさない → 開始しない**。単発＋マガジンで続け、60日後に再判断。

## 2. コンセプト

**名前案**：「お金をかけすぎない実践ノート」／「気づきを小さな選択に変える部屋」／「遠回りの分解室」

```
ここは、もうお金をかけすぎない人のための場です。
気づきを小さな選択に変える習慣を、それぞれのペースで続けます。

・「ここにいないと叶わない」場所ではありません
・自分で考えて、自分で選べるようになることがゴールです
・卒業（退会）は、いつでも、気軽にどうぞ
```

**依存させない設計**
- 「卒業」を前向きに扱う（例：「3か月続けて、自分で問いを立てられるようになったら卒業もおすすめです」）
- 特典記事に毎回「この問いを自分で立てるコツ」を入れる
- 個別回答はしない（相談回答は記事として全員に共有）
- 相談回答の型と科学的根拠のルールを、単発記事と同じく適用

## 3. プラン設計

### 推奨：1プランのみ（月額800円）
- プラン名：「実践ノート」
- 理由：1,000円未満で心理的ハードルが低く、500円より運用負荷に見合う。プランを増やすと特典管理が煩雑になる

### 2プランにする場合
| プラン | 月額 | 内容 |
|---|---|---|
| 読むプラン | 500円 | 週1ワーク記事、月1振り返り、相談回答アーカイブ |
| 実践プラン | 1,000円 | 上記＋掲示板での実践記録共有、毎月の「実践ノート」テンプレート、過去の有料記事（指定の数本）が読める |

**やらないこと**：上位プランでの個別鑑定・個別セッション・高額講座への誘導、「上位プランの人だけ叶いやすい」と思わせる表現

### 単品購入とメンバー参加を選べる設計
- 有料記事を作るときに「メンバーシップ特典にも追加」設定（メンバーは追加料金なしで読める）
- 商品一覧ページに「単品で買う／メンバーとして読む」の両方を明記
- 「メンバーの方が得です」と押さない。「毎週読みたい方はメンバー、特定のテーマだけ読みたい方は単品がおすすめです」

## 5. 掲示板・コミュニティのルール

### 掲示板ガイドライン全文

```
【掲示板ガイドライン】

この掲示板は、メンバーの皆さんが「今週の小さな選択」や気づきを、
それぞれのペースで記録・共有する場所です。参加は任意です。読むだけでも大歓迎です。

■ 大切にしていること
・盲信しない、否定もしない
・自分を責めない。人も責めない
・答えは一人ひとり違う

■ お願いしたいこと
1. 他のメンバーの書き込みを否定・批判しないでください。
   アドバイスは、相手が求めている場合だけにしましょう。
2. 他の講師・講座・メソッド・発信者への批判はご遠慮ください。
   「自分には合わなかった」という体験の共有はOKです。
3. 勧誘・宣伝（他のサービス、講座、商品、SNSアカウント、副業など）は禁止です。
4. メンバー同士での個別の連絡先交換・DMでの勧誘はご遠慮ください。
5. ここで読んだ他のメンバーの相談内容・書き込みを、外部（SNS、ブログ等）に持ち出さないでください。
   スクリーンショットの共有も禁止です。
6. 個人が特定される情報（本名、勤務先、住所など）は書かないでください。
7. 霊感・開運・運気を理由に、他のメンバーの行動を促すことはご遠慮ください。

■ オーナーの返信について
・すべての書き込みに個別に返信することはできません。
・いただいた内容は、個人が特定されない形で、ワーク記事の中で全体に向けて回答することがあります。
  紹介してほしくない場合は、書き込みに「紹介不可」と書いてください。
・返信は原則として週1回（日曜）にまとめて行います。

■ 専門家に相談した方がいい悩みについて
DV、借金、病気、強い落ち込み、死にたい気持ちなど、
この場で扱える範囲を超える悩みについては、専門の窓口をご案内します。
あなたを突き放すためではなく、あなたの安全を一番に考えるためです。

■ ガイドラインに反する書き込みについて
オーナーの判断で非表示・削除することがあります。
繰り返される場合は、退会のお願いをすることがあります（その場合、その月の会費はnoteの仕様により返金されます）。

■ 改訂
このガイドラインは、必要に応じて改訂します。改訂時はお知らせします。

［制定日：2026年　月　日］
```

### 自分責めにつながる発言へのフォロー

例：メンバー「また今週もできませんでした。私は本当にダメですね」

```
書いてくださってありがとうございます。
「できなかった」と気づけたこと自体が、ひとつの記録だと思います。
私も［遠回りの一言］な週がたくさんありました。
今週は「できたこと」を探すより、「できなかった理由」を1つだけ眺めてみる週にしてもいいかもしれません。
習慣になるまでの期間は人によって大きく違う、という研究もあります。
自分のペースで大丈夫です。
```
ポイント：①書いたことを肯定 ②自分の経験で並ぶ ③「ダメ」を否定も肯定もせず、視点を1つ足す ④研究は軽く添える程度

### 専門家領域の相談への定型文

```
大切なことを書いてくださって、ありがとうございます。
お書きいただいた［DV／借金／体調／気分の落ち込み］のことは、
この場や考え方の工夫だけで扱うには大きすぎる問題だと感じています。
あなたの安全と健康を一番に考えて、専門の窓口に相談していただけたらと思います。

・身の危険を感じるとき：警察 110／DV相談ナビ #8008
・借金・お金のトラブル：法テラス 0570-078374／消費者ホットライン 188
・体調・気分の落ち込みが続くとき：医療機関、こころの健康相談統一ダイヤル 0570-064-556
・死にたい気持ちがあるとき：よりそいホットライン 0120-279-338

相談するのは、弱いことではありません。
落ち着いたら、またここで、あなたのペースで書いてください。
```
※番号は公開前・定期的に各公式サイトで最新を確認。掲示板（全員が見る場所）での相談なら、個人の事情に触れすぎず短く返し、本人の書き込みを非表示にするかどうかは本人の意向を優先する。

### 返信ポリシー（紹介ページと掲示板に明示）
- 全件に個別回答しない（記事でまとめて回答）
- 掲示板の確認は週1回（日曜）
- DMでの個別相談は受け付けない
- 回答は「考え方の整理」であり、医療・法律・お金の助言ではない

## 6. 退会・トラブル対策

### 退会方法の明示（紹介ページ・毎月の振り返り記事の末尾に）
```
【退会について】
退会は、メンバーシップページの「プランの管理」（※表記はnoteの仕様による）からいつでもできます。
次回の請求日の前日までに退会すれば、次回以降の請求は発生しません。
引き止めはしません。卒業も、お休みも、あなたの選択です。
戻りたくなったら、いつでもどうぞ。
```

### 使わない表現
| NG | 言い換え |
|---|---|
| 抜けると運気が下がります | （書かない） |
| 今入らないと損です | 毎週読みたい方はメンバーが便利です |
| ここにいる人だけが叶っています | （書かない） |
| 退会した人は戻れません | いつでも戻れます |
| 続けないと効果がなくなります | 自分のペースで続けられる形を探してください |

### 特典内容の変更・縮小時の告知ルール
1. **変更の30日以上前**に、メンバー向け記事と掲示板で告知
2. 変更内容・理由・開始日・既存メンバーへの影響を明記
3. 縮小する場合は「縮小前に退会する選択肢」を案内
4. 会費の値上げをする場合は、既存メンバーへの適用時期をnoteの仕様に従って明記（**仕様は要確認**）
5. 告知例：「◯月◯日から、週1回のワーク記事を月3回に変更します。理由は［ ］です。内容の質を保つための変更です。変更に合わない方は、◯月◯日の請求日前日までに退会いただければ次回以降の請求は発生しません」

### 返金に関する注意事項（noteの仕様を踏まえて）
```
【会費の返金について】
メンバーシップの会費は、noteの仕様により原則として返金できません。
ご参加前に、紹介ページの特典内容とサンプル記事をご確認ください。
なお、ガイドライン違反等によりオーナーが退会をお願いした場合、その月の会費はnoteの仕様により返金されます。
```
※請求日・無料期間の扱い（2026年8月の変更）を公開前に必ず確認し、文面を合わせる。

### 8-6. やってはいけない運用と言い換え

| NG運用 | 理由 | 言い換え・代替 |
|---|---|---|
| 「抜けると運気が下がる」 | 霊感・開運を理由にした引き止め | 「卒業もお休みも、あなたの選択です」 |
| 「今月入らないと過去記事が読めなくなる」と急かす | 限定性の煽り | 「過去記事の公開範囲はプランの仕様に従います」（事実のみ） |
| 上位プランで個別セッション | ポジションの崩壊・依存・トラブル | 個別対応はしない |
| メンバーだけに「叶う秘密」を出すと匂わせる | 誇大・依存 | 「毎週の問いとワークを届けます」 |
| メンバーの書き込みを許可なく紹介 | プライバシー侵害 | 「紹介不可」の意思表示を尊重、要約して匿名化 |
| 退会者を名指しで惜しむ投稿 | 圧力 | （しない） |
| 特典を予告なく減らす | 信頼・トラブル | 30日前告知 |
| 「叶った報告」だけをピックアップして宣伝 | 体験談の誤認 | 「続けやすかった」「考え方が整理できた」など内容の声を中心に |
| メンバー同士の勧誘を放置 | 二次被害 | ガイドラインで禁止、該当書き込みは非表示 |
| 専門家領域の相談に考え方で答える | 安全上の問題 | 定型文で窓口案内 |
