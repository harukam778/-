# 08. 検索流入からnoteを売る方法

> 民間のSEO解説（出典C5）と一般的なSEOの考え方に基づく。noteの検索・レコメンドの内部仕様は非公開のため**仮説**として運用し、noteのアクセス解析で検証すること。2026年はnote公式が「レコメンドエンジンの改善」「llms.txt対応（AIが読み取りやすく）」を進めている（出典A9）。

## 1. 検索で読まれるタイトルの作り方

```
［検索キーワード（前半）］＋［悩みの具体化 or 数字］＋｜＋［あなたならではの切り口］
```
- キーワードは**前半**に置く（Googleでは後半が省略されやすい）
- 全体で**30〜35字**目安（note内の一覧ではもう少し長くても表示される）
- 数字（3つ・7つ・30項目）を入れるとクリックされやすい（仮説）
- 「必ず」「確実」は使わない（規約・景表法・信頼の観点）

例：`引き寄せが叶わない人に多い3つの思い込み｜約300万円使った私の振り返り`

## 2. キーワード選定方法（無料でできる手順）

1. **Google検索のサジェスト**：「引き寄せ 」と入力して出る候補をメモ（スペース後に あ〜わ を入れると候補が増える）
2. **Googleの「他の人はこちらも質問」「関連する検索」**をメモ
3. **note内検索**で同じ語を検索し、上位記事のタイトルの“型”と記事数を確認（本文は真似しない）
4. **ロングテール（3語以上）を優先**：「引き寄せ 叶わない 苦しい」など。競合が少なく、悩みが具体的＝購入に近い
5. **購買意図の強さで分類**：
   - 強：「〜 講座 迷う」「〜 高額 後悔」「〜 やり方 わからない」
   - 中：「〜 叶わない 理由」「〜 できない」
   - 弱：「〜 とは」「〜 意味」
6. 1記事＝1メインキーワード＋関連語2〜3個

## 3. 記事冒頭の書き方（最初の200字で答える）

```
「［検索キーワード］」で検索したあなたは、［悩みの状況］かもしれません。
結論から言うと、［考えられる理由を一言］。
この記事では、引き寄せ・潜在意識に約300万円使った私の経験と、心理学の研究をもとに、
［得られること3つ］をまとめます。
```
- 結論を先に。AIの要約（Google AI Overview等）に引用されやすい書き方でもある（仮説）
- 「私は誰か」を1行で示す（経験の信頼性）

## 4. 見出し設計

```
H2：［キーワード］とは／よくある状態
H2：［キーワード］の考えられる理由3つ
  H3：理由① ……
  H3：理由② ……
  H3：理由③ ……
H2：今日からできる小さな選択
H2：科学的に言えること・言えないこと
H2：専門家に相談した方がいいケース
H2：まとめ
```

## 5. 内部リンク設計

- **固定記事「はじめての方へ｜記事一覧」**（第12章）をハブにして、全記事の冒頭か末尾からリンク
- 無料記事同士は**同じ悩みカテゴリ内で2〜3本**リンク（例：恋愛×叶わない → 恋愛×執着 → 恋愛×連絡待ち）
- 無料記事 → 有料記事は**末尾に1回**
- 無料マガジン（悩み別）を4つ作る：「恋愛」「お金」「仕事」「人間関係」＋「高額講座の見極め」「科学で読む引き寄せ」
- ハッシュタグは**5個前後**：`#引き寄せ` `#潜在意識` `#願望実現` ＋ 悩み別タグ（`#恋愛` `#自己肯定感` など）＋ 独自タグ（`#叶わない理由の分解`）

## 6. 無料記事と有料記事の組み合わせ（クラスター）

| 有料記事（受け皿） | 無料記事（入口・3〜5本） |
|---|---|
| 高額講座の前に読むチェックリスト | 「引き寄せ 講座 迷う」／「スピリチュアル 講座 高額 後悔」／「自己啓発セミナー 見分け方」 |
| 叶わないときの見直しガイド | 「引き寄せ 叶わない」／「潜在意識 書き換え できない」／「引き寄せ 疲れた」 |
| 本当に使えるワーク12選 | 「引き寄せノート 書き方 続かない」／「アファメーション 逆効果」／「感謝ノート 意味ない」 |
| Want to／偽りの願望ワーク | 「本当の願い わからない」／「偽りの願望 見分け方」／「やりたいことがわからない」 |
| 科学で読み解く引き寄せ | 「引き寄せ 科学的根拠」／「引き寄せ 嘘」／「RAS 引き寄せ 本当」 |
