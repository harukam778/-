# 05. 有料noteの構成テンプレート

## 1. 全体構成（目安：10,000〜20,000字、無料部分は全体の20〜30%）

```
【無料部分】
 1. タイトル
 2. 冒頭の問題提起（共感）……………… 300〜500字
 3. このnoteで得られること…………… 箇条書き5つ
 4. 想定読者／この記事に向かない人
 5. 専門家に相談した方がいい悩み（線引き）
 6. 私について（300万円の遠回り・一言で）
 7. 目次（※無料部分に置く）
 8. 無料で読める「本編の一部」（1章の前半など）
 9. 注意事項・返金について
 ───────── ここから有料 ─────────
【有料部分】
10. 本編（相談回答の型で章立て）
11. ワーク（手順・記入例）
12. よくある失敗と見直し方
13. 科学的に言えること・言えないこと
14. 最後の行動提案（今日の小さな選択を1つ）
15. 参考文献
16. 改訂履歴
```

**有料ラインの位置**：「目次」＋「本編1章の前半」まで無料にして、**読者が“中身の質”を確認できるところ**で区切る。無料部分だけで判断できるようにすると、返金申請も減りやすい（仮説）。

## 2. そのまま使える本文テンプレート

> `［ ］` を埋めて使う。【 】はメモなので削除。

---

### タイトル

`［悩み・状況］のときの［見直しガイド／ワーク／チェックリスト］｜［約300万円の遠回りから／心理学の研究と実践の記録から］`

例：`叶わない時期の見直しガイド｜約300万円の遠回りから残った7つの視点とワーク`

### 冒頭の問題提起

```
ノートに願いを書いて、感謝もして、イメージもしている。
なのに［現実が動かない／むしろ苦しくなっている］。

「まだ潜在意識が書き換わっていないのかな」
「私のやり方が間違っているのかな」
そう思って、次の本や講座を探してしまう。

私もそうでした。
本、セミナー、継続講座……気づけば約300万円を使い、
それでも何年も［願い］が叶わない時期がありました。

このnoteは、その遠回りを分解して
「どこを見直せばよかったのか」を、私の経験と心理学の研究をもとに整理したものです。
「このやり方なら叶います」という約束はできません。
そのかわり、自分で見直せる場所を一緒に探します。
```

### このnoteで得られること

```
・叶わない時期に「見直す場所」を7つの視点で整理できます
・それぞれの視点で使えるワーク（手順と私の記入例つき）
・恋愛／お金／仕事／人間関係のケース別の考え方
・心理学の研究で「言えること・言えないこと」
・今日からできる小さな選択の決め方
```

### 想定読者／この記事に向かない人

```
【こんな方に向けて書きました】
・引き寄せや潜在意識の方法を試してきたけれど、変化を感じられない方
・高額な講座に申し込む前に、自分でできることを確かめたい方
・盲信はしたくないけれど、内側を見直すことには興味がある方

【この記事に向かない方】
・「これをやれば必ず叶う」という方法を探している方（そういう約束はできません）
・すぐに目に見える結果が欲しい方
・スピリチュアルな説明（波動・宇宙など）を中心に読みたい方
```

### 専門家に相談した方がいい悩み（線引き）

```
次のような状況にある方は、このnoteより先に専門の窓口に相談してください。
引き寄せや考え方の見直しで扱える範囲を超えています。

・DVやモラハラなど、身の危険を感じる → DV相談ナビ（#8008）、警察（緊急時110）
・借金や返済の悩み → 法テラス（0570-078374）、各地の消費生活センター（188）
・眠れない、食べられない、気分の落ち込みが続く → 医療機関、こころの健康相談統一ダイヤル（0570-064-556）
・死にたい気持ちがある → よりそいホットライン（0120-279-338）、いのちの電話
・契約や返金のトラブル → 消費者ホットライン（188）

※窓口の番号は公開時に各公式サイトで最新のものを確認してください。
```
【注：窓口番号は記事公開前に必ず公式サイトで最新確認すること】

### 私について

```
［ニックネーム］です。
引き寄せ・願望実現・潜在意識のメソッドやセミナーに約300万円を使いました。
効いたこともあれば、効かなかったこともあります。
何年も願いが叶わなかった時期を経て、変わり始めたきっかけは［記入］でした。
今は「盲信しない、否定もしない」立場で、遠回りの中身を正直に書いています。
```

### 目次（無料部分）

```
1. まず知ってほしいこと：叶わないのは「あなたがダメだから」ではない
2. 見直す場所① 見えなくなっているもの（スコトーマ）
3. 見直す場所② その願いはWant toか、Have toか
4. 見直す場所③ 自分で変えられる場所
5. 見直す場所④ ゴール側から今を見る
6. ケース別：恋愛／お金／仕事／人間関係
7. 今日の小さな選択を決める
8. よくある失敗
9. 科学的に言えること・言えないこと
10. 参考文献
```

### 本編：相談回答の型で各章を書く

各章は次の7ステップで書く（第0章の「相談回答の型」）。

```
■ 見直す場所①：見えなくなっているもの

【よくある状態】
「［よくある悩みを、複数の声を混ぜて自分の言葉で要約］」

【1. 思い込み・見えなくなっているもの】
［例：「連絡が来ない＝嫌われている」という前提に立つと、それ以外の可能性が目に入りにくくなる］

【2. その願いはWant toか】
［問い：その願いは、誰かに認められるためのものになっていないか？］

【3. 自分で変えられる場所】
［相手の行動は変えられない。でも、自分の時間の使い方は選べる］
※「あなたのせい」ではなく「ここなら動かせる」という視点です。

【4. ゴール側から見る】
［1年後の理想の自分なら、今日のこの状況をどう過ごすか］

【5. 今日できる小さな選択】
［例：「スマホを見たくなったら、3行だけノートに書く」と決めておく］

【6. 私の遠回り】
［例：私はここで、次の講座を買って“答え”を探しました。結果は……］

【7. 科学的に言えること】
人は注意を向けているものしか見えにくい、という研究があります
（例：Simons & Chabris, 1999）。
ただしこれは「ゴールを決めれば現実が引き寄せられる」ことを示したものではなく、
「注意の向け方で気づける情報が変わる」ことを示したものです。
```

### ワーク（手順・記入例）

```
【ワーク：Want to／Have to 仕分け（所要15分）】
準備：紙とペン（スマホのメモでも可）

手順
1. 叶えたいことを5つ書き出す
2. それぞれに「誰にも知られなくても、やりたい？」と問い、○△×をつける
3. △×のものに「本当は何が欲しい？」を1行書く
4. ○のものから1つ選び、今日できる5分の行動を決める
5. 「もし［いつ・どこで］になったら、［行動］をする」の形で書く

私の記入例
1. 年収を上げたい → △（本当は：安心したい）
……

向かない人：書き出すと気持ちが大きく沈む方は、無理に続けずに休んでください。
```

### よくある失敗

```
・失敗1：ワークを「正解探し」にしてしまう → 正解はありません。違和感をメモするだけでOK
・失敗2：1日で全部やろうとする → 1日1ワークで十分
・失敗3：変化がないと自分を責める → 研究では習慣化に平均66日、個人差が大きいとされています
……
```

### 科学的に言えること・言えないこと

```
【言えること（研究がある）】
・「もし〜なら〜する」と決めておくと、行動に移しやすくなるという研究の蓄積がある
  （Gollwitzer & Sheeran, 2006 のメタ分析）
・理想だけでなく障害も考えるWOOPは、目標達成に小〜中程度の効果があるとされる
  （Wang et al., 2021）

【言えないこと】
・これらの研究は「願いが宇宙に届く」「潜在意識を書き換えれば叶う」ことを示したものではありません
・「潜在意識が99%」のような数字には、確かな根拠を見つけられませんでした
・量子力学で引き寄せを説明することはできません
```

### 最後の行動提案

```
最後まで読んでくださって、ありがとうございます。

全部やらなくて大丈夫です。
今日は、ひとつだけ選んでください。
・ワーク①の「5つ書き出す」だけ
・または、明日の自分への「もし〜なら〜する」を1行だけ

それで十分です。
［私自身、変わり始めたのは大きな決断ではなく、［記入］という小さな選択からでした。］

もし感想があれば、Xで教えてもらえるとうれしいです（任意です）。
いただいた感想を紹介させていただく場合は、必ず事前にご本人に確認します。
```

## 3. 書き方の細かいルール

### 「個人の体験であり効果を保証しない」の自然な書き方
- ×「※効果には個人差があります」（定型文だけ）
- ○「これは私に起きたことで、同じことがあなたに起きるとは限りません。だからこそ、効かなかったことも一緒に書いています」
- ○「私の場合は〜でした。合わなかった方のために、別の選び方も書いておきます」
- 注意：消費者庁の調査では、**体験談に打消し表示を添えても「多くの人が同じ効果を得られる」と受け取られやすい**とされています（出典B2）。だから**体験談そのものを“成功例だけ”にしない**ことが最大の対策です。

### ステマ・誇大広告を避ける表現
| 避ける | 言い換え |
|---|---|
| 必ず叶う／100％ | 見直す視点が増える／選べることが増える |
| 人生が激変 | 小さな選択が変わる |
| 今だけ／残りわずか | （書かない）価格を変える場合は事前告知 |
| 購入者の9割が効果を実感 | （根拠のない数字は書かない） |
| 知人に頼んだ高評価レビュー | （しない）感想は本人同意＋謝礼があれば「謝礼あり」と明記 |
| 潜在意識を書き換えて願いを現実化 | 思い込みに気づいて、選び方を見直す |
