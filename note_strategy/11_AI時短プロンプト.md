# 11. AIを使った時短手順

## 大原則

1. **AIの出力をそのまま販売しない**。必ず「私の経験・検証・具体例・独自視点」を入れる（目安：完成稿の半分以上が自分の言葉）
2. AIに**本・講座の文章を入力して書き換えさせない**（依拠性が生じ、類似すれば著作権侵害のおそれ。出典B9）
3. AIが出した**研究・統計・出典は必ず自分で実在確認**（AIは架空の論文を作ることがある）
4. AIに「体験談」「口コミ」を作らせない（架空の体験談＝景表法上の問題。出典B10）
5. 他人の投稿・知恵袋の原文をAIに貼らない（個人情報・著作権）。自分で要約したメモだけを渡す

## 作業フロー

```
①リサーチ → ②読者ニーズ分析 → ③悩み要約 → ④構成 → ⑤タイトル
→ ⑥無料部分 → ⑦有料部分（自分の体験を挿入）→ ⑧X投稿
→ ⑨チェック4種（誇大／著作権・商標／科学／自分責め・専門家領域）→ ⑩自分で最終推敲
```

## プロンプト集（コピーして使う）

共通の前置き（すべてのプロンプトの先頭に付ける）：

```
あなたは、引き寄せ・潜在意識ジャンルで「盲信しない、否定もしない」立場の発信を手伝う編集者です。
筆者は、願望実現のメソッドやセミナーに約300万円を使い、効かなかった方法も経験した実践者です。
次のルールを守ってください。
- 「必ず叶う」「人生激変」「今だけ」など断定・煽り・限定表現を使わない
- 不安をあおらない。霊感・開運を理由に行動を迫らない
- 「自分原因」を自分責めにしない。「自分で変えられる場所がある」という希望の側から書く
- DV・借金・病気・うつ状態などは専門家・相談窓口へ案内する
- 医療・投資・法律・税金・健康改善の断定をしない
- 科学は「証明」ではなく「〜という研究がある」「〜と考えられている」と書く。量子力学、RASを願望のフィルターとする説明、「潜在意識99%」等の数字は使わない
- 特定の講座・講師・メソッド名を批判しない。メソッド名や登録商標を見出しや商品名に使わない
- 実在しない体験談・口コミ・数字を作らない。筆者の体験が必要な箇所は【筆者の体験を挿入】と書いて空欄にする
```

### ① リサーチ用
```
［テーマ：例「引き寄せが叶わない」］について、読者がどんな言葉で検索し、どんな不安や疑問を持っているかを整理してください。
出力：
1. 検索されそうなキーワード（3語以上のロングテール中心）20個
2. 読者の疑問を「表の悩み／奥にある悩み」の2列で10組
3. このテーマで一般的に語られている主張と、その主張に対して慎重になるべき点
※特定のサイトや記事の文章を引用しないでください。事実や統計を挙げる場合は、確認すべき一次情報の種類（例：論文、公的機関）を示し、具体的な数字は「要確認」と付けてください。
```

### ② 読者ニーズ分析
```
想定読者：［例：引き寄せを3年以上実践しているが変化を感じられず、高額講座を検討している30〜40代］
この読者について、
1. 今の状況・感情・よく言うセリフ（推測）
2. 有料noteにお金を払う理由（得たいもの）と払わない理由（不安）
3. この読者が「押し売り」と感じる表現の例
4. この読者が「信頼できる」と感じる要素
を表で整理してください。推測であることを明記してください。
```

### ③ 悩み抽出と匿名化・要約
```
以下は、私が複数の悩み（質問箱・自分の過去・よく見かける傾向）を自分の言葉でメモしたものです。
［メモを貼る ※他人の投稿の原文は貼らない］
これを、
- 個人が特定されない形（年齢・地域・職業・固有名詞を削除または一般化）
- 複数の悩みを混ぜた「よくある悩み」1〜2文
に要約して、5パターン作ってください。原文に含まれる特徴的な言い回しは使わないでください。
DV・借金・病気・希死念慮など専門家領域の内容が含まれる場合は、そのメモに【専門窓口案内】とラベルを付けてください。
```

### ④ 有料note構成作成
```
次の有料noteの構成案を作ってください。
- タイトル案：［ ］
- 価格：［ ］円
- 想定読者：［ ］
- 筆者の材料：［自分の経験メモを箇条書きで］
構成ルール：
- 無料部分：問題提起／得られること／想定読者／向かない人／専門家領域の線引き／筆者紹介／目次／本編1章の前半／注意事項
- 有料部分：各章を「相談回答の型」（①見えなくなっているもの ②Want toかHave toか ③自分で変えられる場所 ④ゴール側から見る ⑤今日の小さな選択 ⑥筆者の遠回り一言 ⑦科学的に言えること）で構成
- ワーク、記入例、よくある失敗、科学的に言えること・言えないこと、行動提案、参考文献
各見出しに、筆者の体験を入れる場所を【筆者の体験を挿入】と示してください。
```

### ⑤ タイトル作成
```
有料note［または無料note］のタイトル案を20個作ってください。
- メインキーワード：［ ］（前半に入れる）
- 切り口：約300万円使った実践者の正直な振り返り／盲信しない
- 30〜40字
- 成果を約束しない（「叶う」「激変」「必ず」「確実」不可）
- 煽り・限定表現不可
各案に「誰向けか」を一言添えてください。
```

### ⑥ 無料部分作成
```
以下の構成で、有料noteの無料部分の下書きを書いてください。
［④の構成のうち無料部分を貼る］
トーン：落ち着いた大人向け、共感はするが煽らない、ですます調。
「個人の体験であり同じ結果を保証しない」ことを、定型文ではなく自然な文章で1回入れてください。
筆者の体験部分は【筆者の体験を挿入】として空欄にしてください。
```

### ⑦ 有料部分作成（相談回答の型）
```
次の章を書いてください。
章タイトル：［ ］
よくある悩み（要約済み）：［ ］
筆者の経験メモ：［自分の体験を箇条書き］
使ってよい研究：［99_出典一覧.md のD欄から選んで貼る］
書き方：
①悩みの奥にある思い込み・見えなくなっているもの
②その願いはWant toか、偽りの願望・Have toか（確かめる問いを2つ）
③自分で変えられる部分（自分責めにならない言い方で）
④少し抽象度を上げ、ゴール側から今を見る問い
⑤今日できる小さな選択を1つ（「もし〜なら〜する」の形）
⑥筆者の遠回りの一言（経験メモから。ないものは作らない）
⑦科学的に言えること（研究名・年を添え、「言えないこと」も1つ）
最後に、この章のワーク（手順5つ以内）を付けてください。
```

### ⑧ X投稿作成
```
以下の無料note［または有料note］の内容から、X投稿を10本作ってください。
［記事の要点を貼る］
配分：遠回りの記録3／見極め方2／小さなワーク・問い3／共感2
- 各140字前後、URLなし
- 断定・煽り・限定表現なし
- 筆者の体験が必要なものは【体験】と書いて空欄に
- 販売告知は含めない
```

### ⑨ リライト
```
次の文章を、意味を変えずに読みやすくリライトしてください。
［文章］
- 1文を60字以内に
- 専門用語には一言の説明を添える
- 断定表現を「〜と考えられています」「私の場合は〜」に
- 私の体験部分の事実（数字・時期・出来事）は変えない
変更点を最後に箇条書きで示してください。
```

### ⑩ 誇大広告・断定表現チェック
```
次の文章を、景品表示法・ステルスマーケティング規制・note利用規約・消費者契約法（霊感等による告知）の観点で、誤認や問題のおそれがある表現をチェックしてください。
［文章］
チェック項目：
1. 効果・成果の断定（必ず、絶対、確実、誰でも、100%、激変、◯日で）
2. 根拠のない数字・実績・ランキング
3. 限定・緊急性の煽り（今だけ、残りわずか、期間限定）
4. 不安をあおる表現、霊感・開運・運気を理由に購入や行動を迫る表現
5. 体験談の使い方（成功例のみ、打消し表示頼み）
6. 広告であることが分かりにくい表現（謝礼のある感想の無表示など）
7. 医療・投資・法律・税金・健康改善の断定
出力：該当箇所／問題の理由／安全な言い換え案 の表。問題がない場合も「問題なし」と明記。
※これは法的助言ではなく、一次チェックです。
```

### ⑪ 著作権・商標リスクチェック
```
次の文章が、以下の人物の著書・講座の表現に近すぎないかをチェックしてください。
人物：宮増侑嬉さん、秋山まりあさん、秦由佳さん、苫米地英人さん
［文章］
チェック項目：
1. 特徴的な言い回し・キャッチフレーズ・独自用語をそのまま使っていないか
2. ワークの手順や図解の構成が、特定の著作のものと酷似していないか（あなたが知っている範囲で）
3. 「◯◯式」「◯◯メソッド」「講座名」「®のついた名称」を見出しや商品名に使っていないか
4. 人物の考え方を紹介するときに「◯◯さんの本から学んだ考え方」と出典を示しているか
5. 引用する場合、引用の要件（必要最小限・主従関係・出典明記・かぎ括弧で区別）を満たしているか
出力：該当箇所／リスクの理由／書き直し案。
※あなたが著作の全文を知らない可能性があるため、最終確認は筆者が原典と照合すること、と最後に明記してください。
```

### ⑫ 科学的根拠チェック
```
次の文章に含まれる科学的・心理学的な主張をすべて抜き出し、チェックしてください。
［文章］
各主張について：
1. 主張の内容
2. 根拠として挙げられている研究（著者・年・誌名）
3. その研究が実在するか、あなたの知識での確信度（高・中・低）。低・中のものは「要確認」
4. 研究の内容に対して、文章が誇張していないか（例：相関を因果として書いていないか、1本の研究で「法則」と言っていないか、効果量の大きさを無視していないか）
5. 推奨する言い換え
特に、量子力学による説明、RASを願望のフィルターとする説明、「潜在意識◯%」などの数字、「21日で習慣化」がある場合は指摘してください。
※最終的な実在確認は、筆者がGoogle Scholar等で行うこと。
```

### ⑬ 自分責め・専門家領域チェック
```
次の文章を、読者の心理的安全の観点でチェックしてください。
［文章］
1. 読者が「叶わないのは自分のせい」「自分がダメだから」と受け取りうる表現
2. 「感情を持ってはいけない」「ネガティブは悪」と受け取りうる表現
3. DV・借金・病気・うつ状態・希死念慮など、専門家に相談すべき悩みを、考え方の工夫で解決できるかのように扱っている箇所
4. 依存を生みうる表現（「ここでしか叶わない」「やめると運が下がる」など）
出力：該当箇所／理由／言い換え案。専門家領域の悩みに触れている場合は、相談窓口の案内文を挿入する位置も示してください。
```

## AI活用の注意点（2026-10-03時点）

- 日本ではAI生成であることの開示を一般に義務づける法律は（2026年時点で）ないとされる（出典B10・民間解説）。ただし**読者の信頼のため**、「構成の整理や校正にAIを使っています。体験・考え方は筆者自身のものです」と自己紹介記事に一言書くことを推奨
- noteの規約・ガイドラインでAI生成物の扱いが更新されることがあるため、公開前に最新の利用規約を確認（出典A11：本文は**未確認**）
