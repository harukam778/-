# 06. 無料記事から有料noteへの導線

## 1. 無料記事の役割（3つ）

| 役割 | 内容 | 例 |
|---|---|---|
| ① 検索の入口 | 「引き寄せ 叶わない」などの悩みで来た人に“答えの一部”を渡す | 「引き寄せが叶わない人に多い3つの思い込み」 |
| ② 信頼の証明 | あなたの経験・正直さ・科学の扱い方を見せる | 自己紹介、300万円の内訳ざっくり版 |
| ③ 有料への橋 | 「もっと深く・自分に当てはめたい人」向けに有料noteを紹介 | 記事末尾のCTA |

## 2. 書くべき内容／書きすぎてはいけない内容

| 無料で書くべき | 無料で書きすぎない（有料に回す） |
|---|---|
| 悩みの「考えられる理由」3つまで | 理由ごとのワーク全手順・記入例 |
| あなたの失敗談の要点 | 失敗の全記録・費用の詳細内訳 |
| 研究の存在と一言要約 | 研究の詳しい解説＋自分への当てはめ方 |
| 今日できる小さな行動1つ | 30日分の実践ステップ |
| チェックリストの一部（5項目） | チェックリスト全30項目＋判断基準 |

**原則：無料記事だけでも「読んでよかった」と思える完結性を持たせる。** そのうえで「自分のケースに当てはめたい人」に有料を案内する。

## 3. 自然な誘導文の型

```
［この記事で書いたこと］の、さらに具体的な手順を知りたい方へ。
［有料noteタイトル］では、［中身1］［中身2］を、私の記入例つきでまとめています。
目次と冒頭は無料で読めるので、合いそうか確かめてから判断してください。
```

### 押し売り感を出さないコツ
- 「必要な人だけ」「合いそうなら」と**選択権を読者に返す**
- **目次と無料部分で判断できる**ことを伝える
- 無料記事の本文中に何度もリンクを貼らない（**末尾1回＋関連記事枠**まで）
- 「読まないと損」系の言葉を使わない

### 信頼を落とすNG表現
| NG | 理由 | 言い換え |
|---|---|---|
| 続きは有料で！（本文の途中で突然切る） | 無料記事の約束違反に感じる | 無料記事は完結させ、末尾で案内 |
| これを知らないと一生叶いません | 不安をあおる | 知っておくと見直しやすくなります |
| 今だけ半額／あと3名 | 過度な限定性 | （書かない） |
| 本当に叶えたい人だけ買ってください | 買わない＝本気じゃない、という圧力 | 合いそうな方だけどうぞ |
| 購入者続々！大反響 | 根拠の曖昧な実績 | （数字を出すなら実数のみ。例：「これまで◯人の方に読んでいただきました」） |
| 宇宙からのサインです | 霊感・開運を理由にした購入誘導 | （書かない） |

## 4. 無料記事タイトル例30

1. 引き寄せに約300万円使った私の全記録（ざっくり版）
2. 引き寄せが叶わなかった数年間、私がやっていた5つのこと
3. 高額講座に申し込む前に、私が自分に聞くようにした3つの質問
4. 「占っても何も変わらない」と感じたときに見直したいこと
5. 潜在意識の書き換えが「できない」と感じる人に多い思い込み
6. 本当の願いと「偽りの願望」の違い｜私が気づくまでにかかった時間
7. アファメーションがつらかった理由を、研究で調べてみた
8. 引き寄せノートを3年続けて、残ったもの・やめたもの
9. 「自分原因」で自分を責めていた頃の私へ
10. 引き寄せを科学で読むと｜言えること・言えないこと（入門）
11. 「21日で叶う」が苦しかった人へ｜習慣化の研究では平均66日
12. メソッド難民だった私が、講座を渡り歩くのをやめた日
13. ポジティブな想像だけでは動けなくなる、という研究の話
14. 連絡が来ない時期に、引き寄せでやってはいけなかったこと
15. 「豊かさマインド」でお金を使いすぎた話
16. 転職したいのに動けないとき、Want toとHave toを分けてみた
17. 感情を抑えない方がいい、と言われる理由（研究の紹介）
18. 叶わない時期に「次の講座」を探してしまう心理
19. 引き寄せに疲れた人へ｜いったん全部やめてみた1か月の記録
20. 300万円のうち「今でも払ってよかった」と思う使い道3つ
21. 300万円のうち「今なら払わない」と思う使い道3つ
22. 私が影響を受けた4人の考え方と、自分の言葉での要約
23. 「スコトーマ」を日常の言葉で説明してみる
24. 叶えたいことを書き出したら、半分は「誰かのため」だった
25. 引き寄せの範囲を超える悩みと、相談先の一覧
26. 男性にもすすめたい「ゴール設定」の考え方（スピなし版）
27. 願いが叶わない時期の過ごし方｜やめてよかった習慣
28. 「ワクワクしなきゃ」に疲れた人へ｜心地よさを基準にする話
29. 引き寄せ系の情報を見分ける、私の5つのチェックポイント
30. 自己紹介｜引き寄せに約300万円使った私が、正直に書く理由

## 5. 記事末尾のCTA例20

1. この記事の続きとして、7つの見直し視点とワークを［有料noteタイトル］にまとめました。目次は無料で読めます。
2. 「自分の場合はどうだろう」と思った方へ。ケース別の考え方を［有料note］に書いています。合いそうなら、のぞいてみてください。
3. チェックリストの全30項目は［有料note］に載せています。申し込みを迷っている方の判断材料になればうれしいです。
4. 今日の記事が役に立ったら、スキやフォローで教えてもらえると励みになります。
5. 次の無料記事では［テーマ］について書く予定です。フォローしておくと通知が届きます。
6. 私の記入例つきのワークは［有料note］にあります。無料部分で雰囲気を確かめてからどうぞ。
7. 似た悩みの記事をマガジン「［マガジン名（無料）］」にまとめています。
8. もっと深く知りたい方向けに［有料note］を用意していますが、この記事だけでも今日の一歩には十分です。
9. 研究の詳しい内容と参考文献は［有料note］で整理しています。
10. 「叶わない理由の分解」シリーズの他の記事はこちら → ［リンク］
11. 質問箱で、引き寄せ・願望実現の悩みを匿名で受け付けています。回答は記事やXで紹介することがあります（個人が特定されないよう要約します）。
12. 高額講座を検討中の方には、［有料note］が「申し込む前の確認」に使えるかもしれません。
13. この記事で紹介したワークの30日版を［有料note］にまとめています。
14. 私の300万円の内訳の詳しい版は［有料note］で公開しています。
15. 感想をXで教えてもらえたらうれしいです（紹介する場合は必ず事前に確認します）。
16. 他の悩み別の記事は、固定記事「はじめての方へ｜記事一覧」からどうぞ。
17. 無料記事だけで十分な方も、もちろん大歓迎です。必要になったときに思い出してください。
18. 恋愛のケースをもっと詳しく知りたい方は［有料note（恋愛編）］へ。
19. 仕事・キャリアのケースは［有料note（仕事編）］で扱っています。
20. 次は「［関連無料記事タイトル］」もあわせてどうぞ。

## 6. 導線図

```
X投稿（悩みの「考えられる理由」）
   └→ リプ欄 or プロフィールのリンク
        └→ 無料note（理由3つ＋今日の一歩）
              ├→ 関連無料記事（内部リンク）
              └→ 末尾CTA → 有料note（目次・無料部分で判断）
                              └→ 購入後：末尾で関連有料note／マガジン案内
固定記事「はじめての方へ｜記事一覧」＝すべての記事からリンク
```
