# 10. 毎日の作業ルーティン

> 共通ルール：**「投稿→リプ→書く」の順**。書く作業は集中力が要るので、毎日少しでも進める。疲れている日は「平日30分」版に落としてOK（ゼロの日を作らないのが目的）。

## 平日30分（最低ライン）

| 時間 | やること |
|---|---|
| 5分 | 予約済みでなければX投稿1本（ストックから） |
| 15分 | 近いジャンルのアカウントへ丁寧なリプライ（3〜5件） |
| 10分 | 悩みメモ・ネタ帳に1〜2個追加（質問箱チェック含む） |

## 平日1時間

| 時間 | やること |
|---|---|
| 10分 | X投稿1〜2本（うち1本はシリーズ「叶わない理由、分解してみた」） |
| 15分 | リプライ（3〜5件）＋自分の投稿へのリプ返信 |
| 30分 | 無料note執筆（見出し1〜2個分）または有料noteの1章分 |
| 5分 | 翌日の投稿を予約／ネタ帳更新 |

## 平日2時間

| 時間 | やること |
|---|---|
| 15分 | X投稿2〜3本作成・予約 |
| 15分 | リプライ（5件前後）＋返信 |
| 60分 | note執筆（無料記事1本の下書き完成 or 有料noteの1〜2章） |
| 20分 | AIチェック（誇大表現・著作権・科学・自分責め：第11章）→推敲 |
| 10分 | 数値の簡易チェック（noteダッシュボード・Xアナリティクス）・メモ |

## 休日3時間

| 時間 | やること |
|---|---|
| 20分 | 今週の数値確認（日曜は `13_数値管理表.csv` 更新） |
| 20分 | 翌3〜4日分のX投稿をまとめて作成・予約 |
| 15分 | リプライ |
| 90分 | 無料note 1本完成 or 有料noteの大きな章を執筆 |
| 20分 | AIチェック→推敲→公開 |
| 15分 | 来週のタスクを1つ決める（9章の表から） |

## 休日5時間

| 時間 | やること |
|---|---|
| 30分 | 数値確認＋競合のタイトルの“型”チェック（本文は読まない／真似しない） |
| 30分 | 翌1週間分のX投稿（約15本）作成・予約 |
| 15分 | リプライ |
| 150分 | 有料noteの執筆（構成→本文→ワーク→記入例） |
| 30分 | AIチェック（全項目）・参考文献の確認 |
| 30分 | 無料記事1本の推敲・公開、内部リンク・ハッシュタグ設定 |
| 15分 | ネタ帳の整理・来週の計画 |

## 1週間のモデル（合計約13〜17時間）

| 曜日 | 版 | 主な成果 |
|---|---|---|
| 月 | 1時間 | X2本、無料note下書き |
| 火 | 1時間 | X2本、無料note下書き続き |
| 水 | 30分 | X1本、リプ、ネタ |
| 木 | 2時間 | X3本、無料note完成→公開 |
| 金 | 30分 | X1本、リプ |
| 土 | 5時間 | 1週間分の投稿予約、有料note執筆 |
| 日 | 3時間 | 無料note1本公開、数値更新、来週計画 |

## リプライ15分のやり方

1. 「リプ先リスト」（20人）から今日の3〜5人を選ぶ
2. 相手の投稿を最後まで読む
3. 「共感（1行）＋自分の経験（1行）＋問い or お礼（1行）」で返す
4. 宣伝・リンクは貼らない。反論しない
5. 自分の投稿についたリプには24時間以内に返信（全件でなくてOK、専門家領域の相談には窓口案内の定型文）
