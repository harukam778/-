# 15. やってはいけない売り方

> 関係する法令・ルール（詳細は `99_出典一覧.md`）：景品表示法（優良誤認・有利誤認・ステマ告示 B1〜B3）、消費者契約法（霊感等による告知の取消し B4）、特定商取引法（表示 A10）、著作権法（B9）、商標法（B11）、note利用規約（A11）。
> ※本章は一般的な情報整理であり法的助言ではありません。判断に迷う場合は弁護士・消費生活センター（188）へ。

## 1. 一覧と安全な言い換え

| カテゴリ | NG例 | なぜダメか | 安全な言い換え |
|---|---|---|---|
| 嘘の実績 | 「受講生1,000人が願いを叶えました」（根拠なし） | 優良誤認・虚偽 | 「これまで◯人の方に読んでいただきました」（実数のみ） |
| 嘘の実績 | 300万円を500万円に盛る | 虚偽の実績 | 「約300万円（記録と記憶からの概算）」 |
| 誇大広告 | 「必ず叶う」「100%」「誰でも」 | 優良誤認、note規約の誤認表現 | 「見直す視点が増えます」「合う方には役立つかもしれません」 |
| 誇大広告 | 「人生が激変する」「30日で別人に」 | 効果の断定 | 「小さな選択を変えるきっかけに」 |
| 限定商法の乱用 | 「今だけ半額」「残り3名」「本日23:59まで」（実際は続ける） | 有利誤認のおそれ、信頼低下 | （使わない）価格改定する場合のみ「◯月◯日から価格を◯円に変更します」と事前告知 |
| パクリ | 他人のnote・書籍・講座の構成や文章を写す | 著作権侵害のおそれ | 自分の経験から構成し、考え方の出典を明記 |
| AI丸投げ | AI生成文をそのまま販売 | 体験のない内容、架空の研究混入 | 第11章：体験を半分以上、研究は実在確認 |
| 不安をあおる | 「このままだと一生叶いません」「やらないと運が下がる」 | 読者の不安につけ込む、信頼喪失 | 「見直しやすくなる視点を紹介します」 |
| 霊感・開運で迫る | 「あなたには悪い気がついている。このnoteで浄化を」「買わないと不幸が続く」 | **消費者契約法の霊感等による告知（取消し対象）に近い構造**。絶対にしない | （書かない）霊感・運気を理由に購入や行動を促さない |
| 返金トラブル | 「返金不可」なのに無料部分がほぼない／返金に関する誤った説明 | トラブル・低評価 | 無料部分で判断できるようにし、noteの返金ルール（有料記事のみ24h・審査あり）を正確に書く |
| ステマ | 知人に頼んだ高評価レビュー、謝礼を伏せた感想、別アカウントでの自作自演 | ステマ規制（景表法）違反のおそれ、規約違反 | 感想は本人同意のうえ紹介、謝礼があれば明記 |
| 医療の断定 | 「うつが治る」「自律神経が整う」 | 医薬品医療機器等法・景表法の問題、健康被害 | 「心身の不調がある場合は医療機関へ」 |
| 投資の断定 | 「このワークで年収が上がる」「お金が入ってくる」 | 収入の保証・断定 | 「お金の使い方を振り返るワークです。投資や収入の助言ではありません」 |
| 法律・税金の断定 | 「この講座は違法なので返金できます」 | 法的助言の範囲 | 「契約で迷ったら消費者ホットライン188へ」 |
| 健康改善 | 「書き出すと免疫が上がる」 | 研究の誇張（筆記開示の効果は小さい） | 「書き出しが気持ちの整理に役立つという研究があります。効果は大きくないともされています」 |
| 高額誘導 | 有料noteの最後で「本気の人は個別セッション（10万円）へ」 | ポジションの崩壊、消費者トラブルの典型パターン | 数千円の記事で完結。個別対応はしない |
| DM勧誘 | フォロワーに「あなたにぴったりの方法があります」とDM | 迷惑行為、勧誘トラブル | DMでの勧誘はしない（プロフィールに明記） |
| 名前の無断使用 | 「宮増侑嬉公認」「苫米地式コーチング」「思考の学校のワーク」 | 誤認、商標・認定制度の問題 | 「◯◯さんの本から学んだ考え方」 |
| 商標の使用 | 「潜在数秘術®で読み解く」を見出し・商品名に | 商標権侵害のおそれ | 使わない。一般名詞で（例：「数字を使った自己理解」も避け、自分の言葉で） |
| 名指し批判 | 「◯◯講座は詐欺」「◯◯先生は嘘つき」 | 名誉毀損・炎上 | 「私には合わなかった。選ぶ前にこの点を確認してほしい」 |

## 2. 炎上しやすい売り方・信用を失う売り方（このジャンル特有）

1. **「叶ったのはこの方法のおかげ」と他人の成功をまとめて宣伝**（生存者バイアス、誇大）
2. **「叶わないのは波動が低いから」**など読者を責める説明（自分責め→反発）
3. **災害・病気・不幸な出来事を「引き寄せた」と語る**（当事者を深く傷つける、炎上の典型）
4. **高額講座卒業→自分も高額講座**（「結局同じ」と見られる）
5. **無料プレゼント→LINE登録→個別相談→高額契約**の導線（行政が注意喚起する典型パターン：B5〜B8）
6. **「稼げるスピリチュアル」**として副業と組み合わせた勧誘（情報商材トラブルと重なる）
7. **フォロワーの悩み投稿を引用リポストして“解説”**（晒し行為）
8. **他の発信者の誤りを公開で指摘**（論争化）
9. **科学用語で権威づけ**（専門家から指摘されて信用失墜）
10. **価格を頻繁に上げ下げ**（「今だけ」と同じ効果、先に買った人の不満）

## 3. 迷ったときのチェック（公開前の5問）

1. この文章を、**一番疲れている読者**が読んで、自分を責めないか？
2. この表現を、**消費者庁の担当者**が読んで、効果を断定していると思わないか？
3. この内容を、**影響を受けた先生本人**が読んで、自分の作品の写しだと思わないか？
4. この研究の紹介を、**その研究者**が読んで、誇張だと思わないか？
5. 1年後に読み返して、**恥ずかしくないか？**
