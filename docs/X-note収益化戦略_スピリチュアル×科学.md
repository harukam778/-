### 0-1. 2026年現在の前提知識（Webで確認済みの事実）

**【事実】noteの手数料（2026年時点）**
- 有料記事・有料マガジン・メンバーシップのプラットフォーム利用料：**10%**
- 定期購読マガジン：**20%**（審査あり）
- 別途、決済手数料：クレジットカード5%／キャリア決済15%／PayPay7%
- 振込手数料：1回270円
- 例：1,000円の記事1本がクレカで売れた場合、手取りは約855円（振込手数料は別）
- 出典：noteヘルプセンター「コンテンツを販売する際に引かれる手数料」

**【事実】Xの収益化条件（2026年時点）**
- 広告収益分配（クリエイター収益分配）：X Premium加入＋**認証済み（課金者）フォロワー500人以上**＋直近3ヶ月で**500万インプレッション以上**
- サブスクリプション機能：認証済みフォロワー2,000人以上（2024年末改定でハードル上昇）
- Tips（投げ銭）：条件なしで設定可能
- 出典：X Help「Creator Revenue Sharing」ほか

→ **【推測】初心者がX本体の収益分配で稼ぐのは非現実的**です（500万インプは上級者でも困難）。Xは「集客と信頼づくりの場」、noteが「販売の場」と割り切るのが2026年の定石です。

**【事実】ステマ規制（景品表示法）**
- 2023年10月から、広告なのに広告と分からない投稿（ステマ）は景品表示法違反
- アフィリエイトリンクを貼る投稿には「PR」「アフィリエイト広告を利用しています」等の明示が必要
- 2024年8月〜2025年7月の1年間で課徴金納付命令の総額は約3.3億円。取り締まりは強化傾向
- 出典：消費者庁「令和5年10月1日からステルスマーケティングは景品表示法違反となります」

**【事実】スピリチュアル・占いジャンル特有の法的リスク**
- 「必ず叶う」「100%当たる」「これを買えば人生が変わる」→ 景品表示法の**優良誤認**にあたる恐れ
- 不安をあおって購入させる（「このままだと不幸になる」等）→ **霊感商法（開運商法）**とみなされるリスク。消費者契約法により契約取消の対象にもなる
- 継続的に販売する場合、特定商取引法の「通信販売」表記が必要になる場合がある（noteの有料記事販売はnoteが決済を担うため個人はnoteの規約に従えばよいが、外部で独自にサービス提供する場合は表記義務を確認すること）
- noteは「必ず儲かる」等の誤解を招く情報商材を規約で禁止。違反は記事削除・アカウント停止・売上没収のリスク
- 出典：消費者庁、各自治体の消費生活センター注意喚起、note利用規約・コミュニティガイドライン

→ **この分野は「稼ぎやすいが、燃えやすく、規制されやすい」ジャンルです。** だからこそ、後述する「脳科学・認知行動学で説明する現実派ポジション」が、差別化と法的安全性の両方を満たす最適解になります。

## 1. 現在のXアカウントの総合診断

アカウントは**これから開設**とのことなので、「既存アカウントの診断」の代わりに、**ゼロから始める人が陥る失敗を先回りで診断**します。

| 診断項目 | 現状 | 放置した場合に起きること |
|---|---|---|
| 何のアカウントに見えるか | まだ何者でもない | 【推測】コンセプトなしで始めると「スピ好きの日記アカウント」になり、フォローする理由が生まれない |
| 誰向けか | 未定義 | 「みんな向け」は「誰にも刺さらない」。読者を1人に絞る必要がある |
| フォローする理由 | まだない | プロフィールを見た人が3秒で「私の悩みを解決してくれそう」と思えなければ通過される |
| プロフィール | 未作成 | 肩書き・実績・提供価値の3点セットがないと信頼ゼロからの発信になる |
| アイコン・ヘッダー | 未作成 | 顔出しなしは問題ないが、フリー素材そのままだと「捨てアカウント」に見える |

| note販売に向いているか | 商品なし | 商品がない状態でフォロワーだけ増やしても収益ゼロ。逆に商品だけ作っても読者ゼロなら売れない。並行で進める設計が必要 |

### 今のままだと売れにくい理由（正直な指摘）

1. **実績が提示できない**：「引き寄せに詳しい」だけでは、同ジャンルの発信者数千人に埋もれます。スピリチュアル系はX上で最激戦区のひとつです【推測】。
2. **「引き寄せで叶えました」系は飽和かつ疑われやすい**：読者は「本当に？」と疑うことに慣れています。証拠や理屈がない体験談は響きにくい。
3. **月100万円という目標と初期状態のギャップ**：正直に言います。**ゼロから90日で月100万円は現実的ではありません**。現実的なラインは「90日で初売上（数千円〜数万円）、6ヶ月で月5万円、1〜2年継続して月30万円圏、月100万円は上位数%」です【推測】。この戦略書は「月100万円を約束するもの」ではなく「そこへ向かう確率を最大化する設計図」です。

### 逆に、あなたが有利な点

- **管理栄養士（国家資格・実務8年）**：スピ系発信者で国家資格＋医療系実務経験を持つ人は少数派。匿名でも「国家資格保有」は名乗れます。

- **脳科学・認知行動学を調べている**：「ふわふわスピ」と「現実派」の間のポジションが空いています（後述）。
- **お金と結婚という2大悩みを自力で解決した実体験**：スピ系読者の悩みの大半は「お金・恋愛結婚・人間関係・健康」。前者2つに実体験があるのは強い。

### 運用ルール

- **毎日投稿の配分（週20時間のうちX運用は約7時間）**：共感系1本＋解説orワーク系1本＋リプ回り30分/日が目安【仮説】
- **伸びやすい時間帯**：朝6-8時、夜20-23時（スピ系読者は夜が強い傾向【推測】）
- **やめた方がいい投稿**：
  - 政治・宗教・他の発信者批判（炎上リスク）
  - 「絶対」「必ず」「100%」を含む断定（景表法リスク＋信頼毀損）

  - 買ったばかりの実績もないのに「稼げます」系の発信

### あなたにとっての結論【仮説】

**「占い×SNS」は追い風。ただし主戦場は変えず、X×note戦略の中に「鑑定」を組み込むのが正解です。**

| 選択肢 | あなたとの相性 | 判断 |
|---|---|---|
| X×テキスト鑑定（ココナラ併用） | ◎ 顔出し不要・文章力が活きる・占い副業経験あり・本戦略の4本目の商品とそのまま一致 | **今すぐやる**（90日プラン内） |
| TikTok/Instagramリール | △ 顔出しなしでも音声+テキスト動画は可能だが、動画制作は週20時間の枠を圧迫。X運用が軌道に乗る前の並行は共倒れリスク | **91日目以降に検討**（noteが1本売れてから） |
| ライブ配信占い | × 声出し・拘束時間・即興対応が必要。匿名性も下がる | やらない |
| AI占い自動販売 | △ 参入者急増で飽和気味。「AIで量産した鑑定」は信頼を毀損するリスク。AIは下書き・効率化の裏方に留める | 表看板にはしない |

**理由（正直な評価）**：
1. 個人鑑定は「初売上」と「実績（鑑定◯件）」を最速で作れる手段で、あなたには既に経験がある。これは本戦略の弱点だった「実績の提示」を埋めます。
2. 一方で鑑定は時間の切り売りなので、鑑定だけで月30万〜100万を目指すと労働地獄になります【推測】。鑑定は「信頼の証拠づくり＋高単価商品」と位置づけ、スケールはnote・マガジン・メンバーシップで狙う二段構えが合理的です。
3. ココナラは7万件超の飽和市場ですが、「脳科学×現実派」の切り口とX導線からの指名買いがあれば埋没を避けられます【仮説】。ココナラ内の検索だけで戦わないこと。
4. 法的注意は本編と同じ：「必ず当たる」「今買わないと不幸になる」は霊感商法・優良誤認のリスク。返金ポリシーと「個人差があります」の明記を徹底。

**90日プランへの反映**：61〜90日目の「個別鑑定テスト販売」を、①ココナラに出品（プラットフォームの信頼と決済を借りる）②Xの固定ポスト・プロフィールから誘導③実績件数と感想（許可済み）をnote「占い副業の始め方」の素材に还流——という三役で使う。
