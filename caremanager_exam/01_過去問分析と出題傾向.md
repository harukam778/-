# 令和8年度（第29回）ケアマネ試験 ― 過去データ分析と出題傾向

作成日：2026年10月4日
試験日：**令和8年10月11日（日）10:00〜**（試験まで残り1週間）

---

## 1. 試験の基本構造（変わらない前提）

| 項目 | 内容 |
|---|---|
| 出題数 | 60問（介護支援分野25問／保健医療福祉サービス分野35問） |
| 試験時間 | 120分（1問あたり2分） |
| 形式 | 5肢複択（「2つ選べ」「3つ選べ」） |
| 合格基準 | **各分野ごとに**正答率70%を基準に、難易度で補正 |
| 注意点 | 片方の分野が基準点未満なら、合計点が高くても不合格 |

---

## 2. 合格率・受験者数の推移（全国）

| 回（年度） | 受験者数 | 合格者数 | 合格率 | 備考 |
|---|---:|---:|---:|---|
| 第21回（H30） | 49,333 | 4,990 | 10.1% | 受験資格を国家資格等に限定した初年度 |
| 第22回（R1） | 41,049 | 8,018 | 19.5% | |
| 第23回（R2） | 46,415 | 8,200 | 17.7% | 過去最低水準の合格者数 |
| 第24回（R3） | 54,290 | 12,662 | 23.3% | |
| 第25回（R4） | 54,406 | 10,328 | 19.0% | |
| 第26回（R5） | 56,494 | 11,844 | 21.0% | 受験者数がピーク |
| 第27回（R6） | 53,699 | 17,228 | **32.1%** | 近年で突出して高い |
| 第28回（R7） | 50,601 | 12,961 | **25.6%** | 前年より6.5ポイント低下 |

### 読み取れること
- **合格率は「20%前後」が基本で、R6の32.1%は例外的に高い年**だった。R7は25.6%で、20%台半ばに戻りつつある。
- **受験者数は3年連続で減っている**（R5 56,494人 → R7 50,601人）。介護人材不足や、ケアマネの処遇・負担感が背景にあるとみられる。
- 合格者数を一定以上確保したいという政策的な事情（ケアマネ不足）はあるが、**合格基準は「正答率70%」から大きく動かない**。合格率が上がるかどうかは問題の難しさ次第。

## 3. 合格基準点の推移

| 回 | 介護支援分野（25問） | 保健医療福祉サービス分野（35問） |
|---|---:|---:|
| 第24回（R3） | 14点 | 25点 |
| 第25回（R4） | 18点 | 26点 |
| 第26回（R5） | 17点 | 24点 |
| 第27回（R6） | 18点 | 25点 |
| 第28回（R7） | 18点 | 25点 |

### 目標点
- 介護支援分野は**3年連続で17〜18点**。**19点以上（76%）**を目標にすると安全。
- 保健医療福祉サービス分野は24〜26点。**26点以上（約74%）**を目標にすると安全。
- 介護支援分野の基準点が高い年が続いているのは、**基本的な問題が多く、受験者の平均点が上がっている**ため。つまり「基本問題を落とさないこと」がそのまま合否を分ける。

---

## 4. 近年の出題傾向（第26〜28回）

### 4-1. 形式面
- 第28回は**「3つ選べ」が60問中48問（80%）**。「2つ選べ」は少なく、**5つの選択肢すべての正誤を判断する力**が求められる。
- 1つでも間違えると0点なので、**「なんとなく知っている」では点にならない**。

### 4-2. 介護支援分野（25問）
第28回は「平易で基本的」という評価が多い一方、**問2「認知症基本法」が難問**だった。

| よく出るテーマ | 第28回の例 | 予想される方向 |
|---|---|---|
| 制度の基本（保険者・被保険者・財政） | 毎年出る | 必ず出る |
| 要介護認定・介護認定審査会 | 問18 | 必ず出る |
| ケアマネジメントの流れ（アセスメント→計画→担当者会議→モニタリング） | 問19 課題分析標準項目、問20 サービス担当者会議 | 必ず出る |
| 介護予防・総合事業 | 問22 基本チェックリスト | 毎年出る |
| **新しい法律・社会の動き** | 問2 認知症基本法 | **今年も1〜2問は出る可能性が高い** |
| 事例問題（3問程度） | 例年どおり | 倫理・自己決定・多職種連携 |

### 4-3. 保健医療サービス分野（20問）
- 他分野より易しいとされた。**高齢者の疾患・検査値・感染症・看取り・在宅医療**が定番。
- 近年は**認知症の新薬、ACP（人生会議）、口腔・栄養・リハビリの一体的取組**など、制度改正や医療の進歩に関係する出題が増えている。

### 4-4. 福祉サービス分野（15問）
- **面接技術・ソーシャルワーク（個別・集団・地域）**、**生活保護**、**成年後見制度**、**障害者総合支援法**、**高齢者虐待防止法**が定番。
- 第28回は**「地域援助（地域を対象にしたソーシャルワーク）」が2年連続**で出題。3年連続の可能性もある。

## 5. 社会情勢と制度の動き（令和8年度に関係するもの）

> **注意**：試験は原則として**試験時点で施行されている法令**に基づいて作られる。2026年に成立した改正法の多くは2027年度以降に施行されるため、**細かい条文がそのまま出る可能性は低い**。ただし「背景知識」として選択肢に入る可能性はある。

| 動き | 時期 | 試験への影響（予想） |
|---|---|---|
| **介護保険法等の改正法が成立**（ケアマネ資格の**更新制廃止**、住宅型有料老人ホームの**登録制**、身寄りのない高齢者への日常生活支援を**第2種社会福祉事業**に、中山間・人口減少地域での基準の弾力化） | 2026年6月成立 | 施行前なので直接は出にくい。ただし**現行の「有効期間5年・更新研修」**は今年も出題対象 |
| **令和8年度の臨時介護報酬改定（+2.03%）**。処遇改善加算の対象に**居宅介護支援・訪問看護・訪問リハ**が追加。ケアプランデータ連携システムへの加入が上乗せ要件に | 2026年6月施行 | ICT・データ連携、人材確保の文脈で出題の可能性 |
| **2割負担の対象拡大は先送り**（第10期＝2027年度の開始前に結論） | 2025年12月 部会意見 | **現行の「1割・2割・3割」の仕組み**の基本問題として出やすい |
| **認知症基本法**（2024年1月施行）、**認知症施策推進基本計画**（2024年12月閣議決定） | 施行済み | 昨年は難問。**今年も出題の可能性が高い** |
| **令和6年度改正・報酬改定**（居宅介護支援事業所による介護予防支援、テレビ電話によるモニタリング、BCP・虐待防止の義務化、身体拘束の適正化の拡大、福祉用具の選択制） | 2024年度施行 | 出題が続いている。**まだ出ていない論点は今年狙われやすい** |
| 帯状疱疹ワクチンの定期接種化（65歳） | 2025年4月 | 感染症・予防接種の選択肢として出る可能性 |
| 猛暑・熱中症特別警戒アラート、能登半島地震など災害 | 継続 | 熱中症・災害時の対応・BCP |
| カスタマーハラスメント対策、ヤングケアラー、8050問題、身寄りのない高齢者 | 継続 | **事例問題のテーマ**になりやすい |

## 6. 残り1週間でやること（優先順位）

1. **介護支援分野の基本問題を確実に取る**（基準点18点が続いている）。保険者・財政・要介護認定・運営基準は、過去問を3年分解き直す。
2. **令和6年度改正の論点を確認する**（テレビ電話モニタリングの要件、介護予防支援の指定、BCP、虐待防止、身体拘束、福祉用具の選択制）。
3. **認知症基本法の数字・主語を覚える**（国＝基本計画は義務、都道府県・市町村の計画は**努力義務**、認知症の日＝9月21日）。
4. **福祉分野の定番3つ**（生活保護・成年後見・日常生活自立支援事業）の「主体」「対象」「誰が申し立てるか」を整理する。
5. 「3つ選べ」が8割なので、**選択肢ごとに○×を書き込む習慣**をつける。
