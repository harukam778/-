# コラム・読み物記事作成スキル

クラウドワークスでコラム・エッセイ・読み物記事を受注・作成するための品質チェックと執筆ガイドです。

## 使い方

```
/column [テーマ] [媒体の雰囲気] [文字数]
```

例: `/column 在宅ワークの孤独感との向き合い方 共感系・30代女性向け 2000字`

---

## コラム作成プロセス

### STEP 1: テーマ・方向性の設定

$ARGUMENTS のテーマについて以下を決めてください。

**記事の「核」を決める**
- 伝えたいメッセージは何か（一言で言えるレベルまで絞る）
- 読んだ後に読者にどう感じてほしいか（共感 / 気づき / 笑い / 感動 / 行動変容）
- 独自の視点・切り口はあるか（ありきたりな内容にしない）

**媒体・読者の把握**
- 媒体のトーン（フォーマル / カジュアル / 共感系 / ビジネス系）
- 想定読者の属性（年齢・性別・ライフスタイル）
- 読者が抱える悩み・興味・価値観

### STEP 2: 構成案作成

コラムは「起承転結」または「PREP法」で構成します。

**パターンA: 起承転結（エモーショナル系）**
```
【タイトル】（読者の感情に刺さる言葉を使う）

【書き出し（起）】
- 具体的なシーン・情景描写から入る
- 読者が「あるある」と感じる共感ポイント

【展開（承）】
- 問題・矛盾・疑問の深掘り
- 自分の体験や気づきを盛り込む

【転換（転）】
- 視点の転換・意外な発見
- 読者の予想を裏切る展開

【結び（結）】
- メッセージを着地させる
- 余韻を残す締め方（説教臭くしない）
```

**パターンB: PREP法（論理系・ビジネス系）**
```
【Point】結論・主張を最初に述べる
【Reason】その理由を説明
【Example】具体例・データ・体験談で裏付け
【Point】結論を再度まとめる
```

**パターンC: 問題提起型**
```
書き出し: 読者が「わかる！」と思う問題提起
↓
その問題の背景・原因を掘り下げ
↓
自分なりの解釈・視点を提示
↓
解決策 or 受け入れ方 or 新しい見方を提案
↓
前向きな締め
```

### STEP 3: 執筆ルール

**書き出しで心をつかむ**
良い書き出しの例：
- 情景描写から入る：「梅雨の蒸し暑い夜、私はまた締め切りを前にPCを閉じた。」
- 問いかけから入る：「あなたは最後に"何もしない時間"を過ごしたのはいつですか？」
- 逆説から入る：「一番孤独を感じるのは、人混みの中にいるときだ。」

**読みやすい文章を書く**
- 一段落は3〜5文を目安にする
- 具体的なエピソード・数字・固有名詞を入れてリアリティを出す
- 抽象論だけで終わらせない（必ず具体例とセットにする）
- 「〜だと思います」より「〜でした」「〜だ」で断言する（自信を持って書く）

**コラムらしい「個性」を出す**
- 書き手の視点・価値観を前面に出す
- 「みんなそう思ってる」ではなく「私はこう感じた」で書く
- 意外な比喩・言い回しを使う
- 完璧な答えを出さなくていい（「〜かもしれない」という余白も大切）

**テンポとリズム**
- 長い文の後には短い文を置く
- 感情が高まる場面は短文・体言止めを使う
- 読者に問いかける文を適度に入れる（「あなたはどうですか？」）

### STEP 4: 品質チェックリスト

**内容チェック**
- [ ] 書き出しの最初の一文が魅力的か
- [ ] 「で、結局何が言いたいの？」に答えられる核があるか
- [ ] 具体的なエピソードや場面が描かれているか
- [ ] 締め方に余韻・メッセージがあるか

**文章チェック**
- [ ] 同じ単語・表現の繰り返しがない
- [ ] 説教・上から目線になっていない
- [ ] 「〜べき」「〜すべき」の多用がない
- [ ] 読後に何か感じるものが残るか

**媒体適合チェック**
- [ ] 発注者が指定したトーン・文体と合っているか
- [ ] 指定文字数の±5%以内に収まっているか
- [ ] NGワード・NGテーマを避けているか

---

## クラウドワークスで評価されるコラムのコツ

**発注者が求めているもの**
- ブランドや媒体の世界観に合った文体
- 読者がシェアしたくなる「刺さる」内容
- 修正が少なく済む完成度の高い初稿

**リピート受注につながる納品**
- 構成意図を一言添えて納品する（「書き出しで共感を引き出し、後半で視点を転換させる構成にしました」）
- 発注者の指示外でも気づいたことはコメントで提案する
- 修正依頼には素直に対応し、理由も聞いて次回に活かす
