# SEO記事作成スキル

クラウドワークスでSEO記事を受注・作成するための品質チェックと執筆ガイドです。

## 使い方

```
/seo-article [テーマ] [ターゲットキーワード] [文字数]
```

例: `/seo-article ダイエット 糖質制限 3000字`

---

## SEO記事作成プロセス

### STEP 1: キーワード分析

$ARGUMENTS のキーワードと記事テーマに基づいて以下を分析してください。

- **メインキーワード**: 記事全体を通じて最も重要なキーワード
- **サブキーワード**: メインKWと合わせて使う関連語（3〜5個）
- **検索意図**: ユーザーが何を知りたいか（情報収集型 / 比較検討型 / 購入型）
- **ターゲット読者**: 年齢・性別・悩み・知識レベルを具体的に設定

### STEP 2: 構成案（アウトライン）作成

以下のフォーマットで構成を作成してください：

```
【タイトル案】（32文字以内、キーワードを含む）

【リード文】（300字程度）
- 読者の悩みに共感
- 記事で解決できることを提示
- 読み進める動機づけ

【本文構成】
H2: ○○とは？基本を解説
  H3: ○○の定義
  H3: ○○のメリット・デメリット

H2: ○○の方法・手順
  H3: STEP1
  H3: STEP2

H2: ○○の注意点
H2: よくある質問（FAQ）

【まとめ】
- 記事の要点を箇条書きで整理
- 読者へのアクションを促す一文
```

### STEP 3: 執筆

以下のルールに従って本文を執筆してください：

**文体・読みやすさ**
- 一文は60字以内を目安にする
- 同じ文末表現（〜です、〜ます）を3回以上連続させない
- 難しい専門用語には必ず説明を加える
- 体言止めを適度に使いリズムをつける

**キーワード配置**
- タイトルにメインKWを必ず含める
- リード文の最初の100字以内にメインKWを入れる
- H2見出しに2〜3回メインKWを含める
- キーワード密度は本文の2〜3%を目安にする（詰め込みすぎない）

**E-E-A-T（品質基準）**
- 経験（Experience）: 実体験・具体的なエピソードを盛り込む
- 専門性（Expertise）: 根拠となるデータ・統計・引用を示す
- 権威性（Authoritativeness）: 信頼できる情報源を参照する
- 信頼性（Trustworthiness）: 誇張・誤情報を避け正確に書く

**図解・リスト活用**
- 3つ以上の要素は箇条書きにする
- 手順は番号付きリストにする
- 比較情報は表にまとめる

### STEP 4: 品質チェックリスト

記事提出前に以下を確認してください：

**構成チェック**
- [ ] タイトルが32文字以内でキーワードを含んでいる
- [ ] リード文で読者の悩みに共感している
- [ ] H2が3〜6個で構成されている
- [ ] まとめがある

**文章チェック**
- [ ] 誤字・脱字がない
- [ ] 一文が長すぎない（60字目安）
- [ ] 同じ文末が3回以上連続していない
- [ ] 根拠のない断定表現（「絶対に」「必ず」）を使っていない

**SEOチェック**
- [ ] タイトルにメインキーワードが入っている
- [ ] リード文の冒頭100字以内にキーワードがある
- [ ] 見出しにキーワードが適度に含まれている
- [ ] キーワードの過剰な詰め込みがない

**信頼性チェック**
- [ ] 統計・データには出典を記載している
- [ ] 医療・法律・金融情報は「専門家への相談を推奨」と注記している
- [ ] 最新情報かどうか確認している

---

## クラウドワークス納品時のポイント

- Wordまたはテキスト形式で納品する場合、見出しレベル（H2/H3）を明記する
- 文字数は指定の±5%以内に収める
- 画像提案がある場合はキャプション案も合わせて提示する
- 修正対応は丁寧に、理由を添えて返答する
