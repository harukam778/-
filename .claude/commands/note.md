# note記事作成スキル（Webライターポートフォリオ＆収益化対応）

noteをWebライターのポートフォリオ兼収益化メディアとして運用するための執筆ガイドです。
管理栄養士×美容ダイエット専門アカウントの運用を想定しています。

## 使い方

```
/note [記事タイプ] [テーマ・キーワード] [文字数]
```

例: `/note SEO解説 タンパク質 1日の摂取量 3000字`
例: `/note コラム 美容クリニック栄養士が見てきた痩せる人の共通点 2000字`
例: `/note 有料記事 1週間ダイエット献立 完全版`

---

## 記事タイプ一覧

| タイプ | 目的 | 文字数目安 | 公開設定 |
|---|---|---|---|
| SEO解説 | ポートフォリオ・検索流入 | 2,000〜5,000字 | 無料公開 |
| コラム | ファン化・人柄を見せる | 1,500〜3,000字 | 無料公開 |
| 有料記事 | 直接収益化 | 3,000字〜 | 有料（300〜2,000円） |
| マガジン用 | シリーズ化・まとめ販売 | 1,500〜2,500字/本 | 有料マガジン |

---

## 全体フロー

```
STEP1 記事タイプ・目的の設定
  └─ ポートフォリオ用 / 収益化用 / ファン化用 を決める
STEP2 構成案作成
  └─ タイプ別テンプレ選択 → 見出し設計 → note特有の読みやすさ設計
STEP3 本文執筆
  └─ PREP法/SDS法 → note読者向け文体 → 専門性×親しみやすさ
STEP4 リード文・まとめ・CTA作成
  └─ 冒頭3行で読者を引き込む → SNS誘導・有料記事への導線
STEP5 品質チェック
  └─ AIっぽさ除去 → note独自ルール確認 → ポートフォリオ品質基準
```

## STEP 1: 記事タイプ・目的の設定

$ARGUMENTS の内容をもとに、以下を確認してください。

```
記事タイプ: （SEO解説 / コラム / 有料記事 / マガジン用）

目的:
  □ ポートフォリオ — クライアントに文章力・専門性を見せる
  □ ファン化 — SNSからの読者を固定ファンにする
  □ 収益化 — 有料記事・マガジンで直接売上を作る
  □ 複合 — ポートフォリオ兼ファン化、など

ターゲット読者:
  （例：ダイエット中の20〜40代女性 / 子育て中のママ / Webライター志望者）

読後に読者に取ってほしい行動（CTA）:
  □ InstagramまたはXをフォロー
  □ 有料記事・マガジンを購入
  □ Webライターとして問い合わせ（ポートフォリオ用）
  □ 次の記事を読む（回遊）
```

## STEP 2: 構成案作成

### SEO解説記事の構成テンプレ

```
【タイトル】（検索されるキーワードを含む・32文字以内）
例：「タンパク質の1日の摂取量｜管理栄養士が体重別に分かりやすく解説」

【リード文】（200〜300字）
  └─ 読者の悩みに共感 → この記事で解決できることを提示

H2: ○○とは？（基本知識・定義）
  H3: 簡単な説明
  H3: なぜ重要なのか

H2: ○○の具体的な方法・手順
  H3: STEP1
  H3: STEP2
  H3: STEP3

H2: よくある失敗・注意点
  H3: NG例とその理由
  H3: 管理栄養士からのアドバイス

H2: よくある質問（Q&A）
  H3: Q1
  H3: Q2

【まとめ】（200〜300字）
【著者プロフィール】（必ず入れる：ポートフォリオ用）
【CTA】（SNS誘導 or 有料記事への導線）
```

---

### コラム記事の構成テンプレ

```
【タイトル】（読みたくなる・共感を呼ぶタイトル）
例：「美容クリニックの栄養士として気づいた、痩せる人と痩せない人の決定的な違い」

【リード文】（150〜200字）
  └─ 体験談・エピソードで引き込む

本文①: エピソード・体験談（現場での気づき）
本文②: 問題提起（なぜそうなるのか・背景）
本文③: 管理栄養士としての視点・解決策
本文④: 読者へのメッセージ・まとめ

【CTA】（SNS誘導 or 次の記事へ）
【著者プロフィール】
```

---

### 有料記事の構成テンプレ

```
【タイトル】（具体的な数字・ベネフィットを入れる）
例：「管理栄養士が作る1週間ダイエット献立｜食べながら-2kgを目指す完全プログラム」

【無料で読める部分】（全体の20〜30%）
  - この記事で得られること（箇条書きで明示）
  - 著者の信頼性（資格・経験）
  - 内容の一部をチラ見せ

【購入後に読める部分】（全体の70〜80%）
  - 具体的なコンテンツ本体（献立・レシピ・プログラム・ガイドなど）
  - 実践のためのワークシートやチェックリスト
  - 読者への個別アドバイス欄（よくある質問）

【購入者へのメッセージ】
【次のコンテンツへの誘導】
```

## STEP 3: 本文執筆

### note読者向けの文体ルール

note特有の読者特性に合わせた書き方をしてください。

```
✅ やること
- 段落は3〜4行で改行（スマホで読みやすく）
- 冒頭の1文は短く・インパクト重視
- 専門用語には必ず一言説明を添える
- 「私が現場で見てきたこと」など実体験を積極的に入れる
- 箇条書きは3〜5個まで（多すぎると読み飛ばされる）
- 小見出し（H2/H3）を活用して読みやすく分割する

❌ やらないこと
- 一段落が5行以上続く
- 専門用語の説明なし
- 「〜である」「〜だ」調（硬すぎる）
- 感情・個性のない無機質な文章
- 同じ語尾が3回以上続く（〜です、〜です、〜です）
```

### 文章の型（PREP法・SDS法）

**PREP法**（専門知識の説明・主張に使う）
```
P（Point）   — 結論を先に述べる
R（Reason）  — 理由・根拠（栄養学的知識）
E（Example） — 具体例・現場でのエピソード・数値
P（Point）   — 結論を再度まとめる
```

**SDS法**（読み物・コラムに使う）
```
S（Summary）  — 全体の要約を先に伝える
D（Detail）   — 詳細・エピソード・具体例
S（Summary）  — 再度まとめて読者に残す印象を作る
```

### 専門性×親しみやすさのバランス

```
【管理栄養士らしさを出す表現例】
「栄養士として現場で感じてきたのは〜」
「美容クリニックで多くの方を見てきた経験から言うと〜」
「専門的に言うと〇〇ですが、簡単に言うと〜」
「保育園から痩身クリニックまで幅広く指導してきた私が〜」

【親しみやすさを出す表現例】
「難しそうに聞こえますが、実はシンプルです」
「私自身も子育て中で、忙しい日々の中で実践していることなので〜」
「完璧じゃなくて大丈夫です」
「一緒に少しずつ変えていきましょう」
```

## STEP 4: リード文・まとめ・CTA作成

### リード文のテンプレ（冒頭3行で読者を引き込む）

```
パターンA：共感型（コラム・ファン化向け）
「〇〇で悩んだことはありませんか？
実は、私が美容クリニックで栄養指導をしていた頃、
そういう方をたくさん見てきました。」

パターンB：結論先出し型（SEO解説向け）
「タンパク質は1日〇〇g摂るべきです。
ただし、これは体重によって変わります。
この記事では、管理栄養士として体重別の目安をわかりやすく解説します。」

パターンC：問いかけ型（有料記事・購買意欲向け）
「食べているのに痩せない——
その原因が『何を食べるか』ではなく
『いつ・どう食べるか』にあるとしたら？」
```

### まとめ文のテンプレ

```
この記事では、〇〇について解説しました。

ポイントをまとめると：
・〇〇
・〇〇
・〇〇

難しく考えなくて大丈夫です。
まずは〇〇だけ意識してみてください。

もっと詳しいレシピ・献立は、Instagramでも毎日発信しています。
ぜひフォローして確認してみてください→ @（アカウント名）
```

### CTA（行動喚起）パターン

```
【SNS誘導】
「毎日の食事tips → Instagram @〇〇 で発信中」
「もっと詳しい情報はXでも発信しています → @〇〇」

【有料記事・マガジン誘導】
「詳しい献立プログラムはこちら → [有料記事リンク]」
「このシリーズの続きはマガジンで → [マガジンリンク]」

【ポートフォリオ用（Webライター向け）】
「食・栄養・美容・子育てジャンルの記事制作承ります。
 お仕事のご依頼はこちら → [問い合わせ先]」
```

## STEP 5: 品質チェック

### ポートフォリオ品質チェックリスト

```
構成・読みやすさ
  □ タイトルにキーワードが含まれているか
  □ リード文で読者の悩みに触れているか
  □ H2/H3見出しが論理的な順序で並んでいるか
  □ 段落が3〜4行以内に収まっているか
  □ 箇条書き・表・太字が適切に使われているか

専門性・信頼性
  □ 管理栄養士としての独自視点・経験が入っているか
  □ 専門用語に説明が添えられているか
  □ 数値・根拠が含まれているか（「タンパク質は体重×1.2g」など）
  □ 著者プロフィール（資格・経験）が記事末尾にあるか

AIっぽさの除去
  □ 「〜することが重要です」「〜が大切です」が続いていないか
  □ 同じ文末表現が3回以上続いていないか
  □ 体験談・個人の言葉が入っているか
  □ 箇条書きだけで終わっている段落がないか

note特有のルール確認
  □ 他サイトへの過度なリンクが含まれていないか
  □ 有料記事の無料部分が全体の30%以内に収まっているか
  □ アイキャッチ画像の指示を含めているか（Canvaで作成推奨）
```

### Webライタークライアント向けポートフォリオチェック

```
  □ 記事を読んで「この人に頼みたい」と思えるか
  □ 執筆ジャンル（食・栄養・美容・子育て）が明確に伝わるか
  □ 構成力（見出し設計・論理の流れ）が示されているか
  □ 読みやすさ（文体・改行・表現）が一定水準以上か
  □ 著者情報（管理栄養士資格・経験）が信頼を与えているか
```

```
X・Instagramで短いtips投稿
       ↓
「詳しくはnoteで解説してます」と誘導
       ↓
noteでSEO解説 or コラムを読む（無料）
       ↓
記事末尾のCTAで以下へ誘導
  ├─ SNSフォロー（ファン化）
  ├─ 有料記事・マガジン購入（収益化）
  └─ Webライター問い合わせ（クライアント獲得）
```
